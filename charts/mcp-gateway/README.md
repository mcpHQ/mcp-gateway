# mcp-gateway Helm chart

Deploys [MCP Gateway](https://github.com/mcpHQ/mcp-gateway), an open source control plane for [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) servers, on Kubernetes.

## TL;DR

```bash
helm install mcp-gateway ./charts/mcp-gateway \
  --namespace mcp-gateway --create-namespace \
  --set gateway.adminPassword=change-me
```

Then port-forward and open the UI:

```bash
kubectl -n mcp-gateway port-forward svc/mcp-gateway 8080:8080
open http://localhost:8080
```

## Architecture notes

- MCP Gateway is a single Go binary with an embedded web UI and an embedded **SQLite** database. The chart therefore deploys **one replica** with a `Recreate` update strategy and a `ReadWriteOnce` PersistentVolumeClaim mounted at `/data`. Do not scale it horizontally unless your storage provides reliable SQLite file locking across pods. See [`docs/SCALABILITY.md`](../../docs/SCALABILITY.md) for why, and for the planned redesign.
- The chart includes opt-in `autoscaling` (HorizontalPodAutoscaler) and `podDisruptionBudget` scaffolding for the gateway Deployment. Both are disabled by default and must **not** be enabled while running on the embedded SQLite backend — they exist for the eventual multi-replica topology described in `docs/SCALABILITY.md`.
- The container runs as a non-root user with a read-only root filesystem; only the data volume is writable.
- Health probes use the built-in `GET /healthz` endpoint.
- The default published image is minimal Alpine, so **stdio MCP servers** (e.g. `npx @modelcontextprotocol/server-filesystem`) are not available in it. Build a custom image with the runtimes you need if you want stdio upstreams in-cluster.

## Secrets

The chart manages a Secret with two optional keys, or you can bring your own via `gateway.existingSecret`:

| Key | Env var | Purpose |
|-----|---------|---------|
| `admin-password` | `MCP_GATEWAY_ADMIN_PASSWORD` | Initial admin password (used only when seeding the first user) |
| `jwt-secret` | `MCP_GATEWAY_JWT_SECRET` | JWT signing secret; if unset, the gateway generates one and persists it in the database |

```bash
kubectl -n mcp-gateway create secret generic mcp-gateway-auth \
  --from-literal=admin-password='change-me' \
  --from-literal=jwt-secret="$(openssl rand -hex 32)"

helm install mcp-gateway ./charts/mcp-gateway \
  --namespace mcp-gateway \
  --set gateway.existingSecret=mcp-gateway-auth
```

### Upstream secret interpolation

Upstream server configuration supports environment variable interpolation for sensitive values (e.g. a server registered with a bearer token of `${GITHUB_TOKEN}`). Inject those variables with `extraEnv`:

```yaml
extraEnv:
  - name: GITHUB_TOKEN
    valueFrom:
      secretKeyRef:
        name: github-credentials
        key: token
```

## Ingress example

```yaml
ingress:
  enabled: true
  className: nginx
  annotations:
    cert-manager.io/cluster-issuer: letsencrypt-prod
  hosts:
    - host: mcp-gateway.example.com
      paths:
        - path: /
          pathType: Prefix
  tls:
    - secretName: mcp-gateway-tls
      hosts:
        - mcp-gateway.example.com
```

## Values

| Key | Default | Description |
|-----|---------|-------------|
| `replicaCount` | `1` | Number of replicas. Keep at 1 (SQLite); ignored when `autoscaling.enabled` |
| `autoscaling.enabled` | `false` | Enable a HorizontalPodAutoscaler (unsafe with embedded SQLite, see above) |
| `autoscaling.minReplicas` | `1` | Minimum replicas when autoscaling is enabled |
| `autoscaling.maxReplicas` | `5` | Maximum replicas when autoscaling is enabled |
| `autoscaling.targetCPUUtilizationPercentage` | `80` | Target average CPU utilization |
| `podDisruptionBudget.enabled` | `false` | Create a PodDisruptionBudget for the gateway |
| `podDisruptionBudget.maxUnavailable` | `1` | Max unavailable pods (ignored if `minAvailable` is set) |
| `image.repository` | `ghcr.io/mcphq/mcp-gateway` | Image repository |
| `image.tag` | `""` (chart `appVersion`) | Image tag |
| `image.pullPolicy` | `IfNotPresent` | Image pull policy |
| `gateway.port` | `8080` | HTTP listen port (`-addr`) |
| `gateway.dbPath` | `/data/mcp-gateway.db` | SQLite database path (`-db`) |
| `gateway.adminEmail` | `admin@mcphq.org` | Initial admin email |
| `gateway.adminPassword` | `""` | Initial admin password (stored in a chart-managed Secret) |
| `gateway.jwtSecret` | `""` | JWT signing secret (generated by the app if empty) |
| `gateway.existingSecret` | `""` | Existing Secret with `admin-password` / `jwt-secret` keys |
| `extraEnv` | `[]` | Extra env vars (upstream secret interpolation) |
| `extraEnvFrom` | `[]` | Extra `envFrom` sources |
| `persistence.enabled` | `true` | Persist `/data` in a PVC (emptyDir when disabled) |
| `persistence.existingClaim` | `""` | Use an existing PVC |
| `persistence.storageClass` | `""` | StorageClass (`-` for empty string) |
| `persistence.size` | `1Gi` | PVC size |
| `service.type` | `ClusterIP` | Service type |
| `service.port` | `8080` | Service port |
| `ingress.enabled` | `false` | Enable Ingress |
| `resources` | `{}` | Container resources |
| `extraVolumes` / `extraVolumeMounts` | `[]` | Additional volumes / mounts |
| `nodeSelector` / `tolerations` / `affinity` | `{}` / `[]` / `{}` | Scheduling controls |

See [`values.yaml`](values.yaml) for the full list, including probes, security contexts, and service account options.

## Uninstall

```bash
helm uninstall mcp-gateway --namespace mcp-gateway
```

The PersistentVolumeClaim is kept by Helm; delete it manually if you also want to remove the gateway state:

```bash
kubectl -n mcp-gateway delete pvc mcp-gateway
```
